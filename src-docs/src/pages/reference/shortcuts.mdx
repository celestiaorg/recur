# Keyboard shortcuts

Recur can be driven from the keyboard: create and switch workspaces, open files, move between the chat, editor, and terminal, change chat modes, and run commands without the mouse.

Press **⌘⇧/** in the app to search every shortcut. On Linux, **⌘** is **Ctrl** and **⌥** is **Alt**.

## Everyday flow

| Do this | Press |
| --- | --- |
| Start a new workspace | `⌘N` |
| Jump to any workspace or pull request | `⌘K` |
| Open a file | `⌘P` |
| Run a bundle command or snippet | `⌘⇧P` |
| Switch the chat mode (Ask, Plan, Agent, Review, Loop) | `⌘.` |
| Add the selected code or file to the chat | `⌘L` |
| Focus the chat, editor, or terminal | `⌘1` `⌘2` `⌘3` |
| Previous or next workspace | `⌥⌘↑` `⌥⌘↓` |
| Go to Terminals (when on in Settings) | `⌥⌘5` |
| Next or previous file in review | `J` `K` |
| Start a project run, such as your dev server | `⌘R` |
| Stop the agent | `⌘⇧⌫` |

## Bundle commands

Bundle commands can declare their own key bindings with `keyEquivalent`. App shortcuts take priority, and commands that share a chord show a numbered picker. See [Manifest](/bundles/manifest#keybindings).

App shortcuts cannot be remapped yet.
