# Agent skills

Skills teach agents reusable procedures (via `SKILL.md` and the Recur MCP skill tools). They are separate from [bundle chat prompts](/bundles/prompts).

## Where they appear

- Composer `/` menu (below bundle prompts)
- `mcp__recur__list_skills` / `activate_skill` for agents

## Settings

- **Settings → Skills**: machine defaults for Recur-shipped and your user skills
- **Project page**: per-project force on/off overrides

Effective state: project disable → off; else project enable → on; else inherit the global default.

Disabled skills are omitted from the agent listing, refused on activate, and hidden from the composer `/` menu.
