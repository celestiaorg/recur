# Install

Recur is a native desktop app for macOS and Linux.

## macOS

1. Download the latest build from [recur.build](https://recur.build/#download).
2. Open the `.dmg` and drag **Recur** into Applications.
3. Launch Recur and complete first-run setup.

At launch the app installs a `recur` command on your `PATH` (a symlink in `/usr/local/bin` when writable, and in `~/.local/bin`). Use `recur .` or `recur <path>` to open a folder or file in Recur, `recur` alone to bring Recur forward, `recur config …` to [change settings from a script](#settings-from-the-terminal), and `recur bundles …` to [author bundles](/bundles/testing).

## Linux

Download the `.deb`, `.rpm` or `.pkg.tar.zst` for your architecture (`linux-amd64` or `linux-arm64`) from [GitHub Releases](https://github.com/celestiaorg/recur/releases/latest) and install it. The package pulls in GTK 4 and WebKitGTK 6.0, installs Recur to `/opt/recur`, and adds `recur` to your `PATH` and Recur to your app menu.

```bash
sudo apt install ./Recur-<version>-linux-amd64.deb   # Ubuntu 24.04+, Debian 13
sudo dnf install ./Recur-<version>-linux-amd64.rpm   # Fedora 40+
sudo pacman -U ./Recur-<version>-linux-amd64.pkg.tar.zst   # Arch Linux
```

On other distributions, install GTK 4 and WebKitGTK 6.0, extract `Recur-<version>-linux-amd64.tar.gz`, and run `recur` from it. At launch it links `recur` into `~/.local/bin` and adds an app-menu entry.

### Verify a download

Each release lists a `SHA256SUMS` file covering every download:

```bash
sha256sum --check --ignore-missing SHA256SUMS
```

The `.deb` and `.rpm` are signed with the [Recur release key](https://recur.build/docs/recur-signing-key.asc):

```
1643 D8F4 CED9 E15A 8779  8A9F 3CDB 8273 A037 2B19
```

To check an `.rpm` signature:

```bash
sudo rpm --import https://recur.build/docs/recur-signing-key.asc
rpm --checksig Recur-<version>-linux-amd64.rpm
```

## Requirements

- macOS (Apple Silicon or Intel), or Linux with GTK 4 and WebKitGTK 6.0 (x86_64 or arm64)
- A configured provider: Claude Code, Cursor, Codex, or a compatible endpoint
- Git 2.31 or newer available on your `PATH`
- Optional: the GitHub CLI (`gh`), signed in, for GitHub pull requests

## Connect your agent

Use first-run setup, then **Settings → Providers** to configure authentication and available models. Existing coding-agent logins can be reused where supported. See [Providers](/reference/agents) for Codex authentication and compatible endpoint requirements.

Your code stays on this machine except for calls to your chosen agent provider and GitHub when you use them.

## Settings from the terminal

`recur config` reads and writes the same settings as the Settings window, so scripts and benchmarks can pin Recur's model, effort and permissions without the GUI:

```bash
recur config list                                   # every setting as key=value
recur config get modelAgent
recur config set modelAgent claude-code/claude-opus-5-5
recur config set flagsAgent '{"effort":"high"}'
recur config set bypassPermissions true
```

Keys are the stored setting names that `recur config list` prints. A value is read as JSON when it parses as JSON, and as a plain string otherwise. Unknown keys and values of the wrong type are rejected and nothing is saved. API keys and other credentials cannot be read or set this way.

It works whether or not Recur is running. When it is, the running app applies the change and the Settings window shows it right away.
