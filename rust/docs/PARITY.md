# Parity inventory

Every surface of the Go/Svelte app that the Rust port must carry over. Nothing here may be dropped. Tick an item only when the Rust implementation matches the original behavior and has a test or a parity screenshot. Each area owner expands their section with the detailed behaviors (edge cases, persistence, keyboard paths) as they port it.

Legend: `[ ]` not started, `[~]` in progress, `[x]` ported and verified.

- [x] **Panics abort the app.** macOS reaches GPUI through `extern "C"` AppKit callbacks and GCD trampolines, so an unwinding panic finds no handler and the process aborts ("failed to initiate panic"); GPUI also takes the window and any leased entity out of the app while it runs a callback, so a catch above GPUI would drop them. `recur_ui::guard` contains panics inside our own callbacks instead: every `Render` / `RenderOnce` body (`guard::view` / `guard::component`, a fallback in the view's place), the pure layout of `recur_ui::text`, the editor and the terminal (`guard::catch`, laid out empty), `recur_ui::guard::Guarded` for every `cx.listener`, `cx.subscribe(_in)` and `cx.observe(_in)` (clippy rejects the raw ones), the editor and terminal mouse handlers and the three `EntityInputHandler`s (the event is dropped with an error toast). The crash hook in `recur_store::applog` logs every panic with a timestamp and backtrace, a repeating one at powers of two. The render and layout audit fixed the markdown mirror's and the chip flow's copies of the line breaker (`9c11b9d4`'s inverted range), stale find highlights and a replaced stream cutting a char, and reversed LSP parameter ranges; `recur-content`'s `markdown_fuzz` lays random markdown out at five widths.
