# Themes & shortcuts

## App themes

Chrome themes are independent of the editor. Built-ins include **Charcoal** (default), **Paper** (light), Slate, Cool Glow, Catppuccin, and Nord.

## Editor themes

The Observatory editor uses TextMate / classic theme ports (Charcoal, Paper, Tokyo Night, Dracula, GitHub Light/Dark, Made of Code, Solarized, Aura, and more). Pair any editor theme with any app chrome theme.

Syntax highlighting is grammar-based (TextMate) and covers TypeScript, Go, Solidity, SVG/XML, and many other languages.

## Keymaps

- App shortcuts for palette, focus, and docks (⌘K Go to, ⌘P Quick Open, ⌘⇧P Run Command, ⌘O Open In…)
- **⌘⇧/** lists every keyboard shortcut
- Editor keymaps: Default, Vim, Emacs (**Settings → Code editor**)
- Diff / editor: **⌘L** tags the selection into chat

## Custom themes

Editor themes can be shipped in a bundle using `[[theme]]`. Recur accepts TextMate theme files, including classic plist and `.tmTheme.json`. Terminal themes use `[[terminalTheme]]` and can be selected independently too.

Put your bundle under `~/.recur/bundles`, choose **Navigate → Reload Bundles**, and use **Settings → Bundles → Themes** to manage contributions. See [Bundles](/bundles) and the shipped Themes bundle for examples.

Custom app chrome themes and fully remappable app shortcuts are not currently available.
