# Settings

Open Settings with **⌘,** (or **Recur → Settings…**). Type in the search field above the section list to filter sections by keyword. Settings apply to every project; where a project can override one, its project page says so.

## App

### General

- **Simplify**: **Default Simplify** turns Simplify on for new chats. Simplify keeps agents from over-building: they reuse what is already in the repo and ship the smallest change that works. You can still toggle it per chat in the composer.
- **Concurrency**: **Max concurrent loops** (default 4) and **Max concurrent agents** (default 8). Extra loops and agent turns wait in a queue until a slot frees. 0 is unlimited.
- **Agents**: **Turn time limit** stops an agent turn after this many minutes (default 240, max 10080). **Queue follow-ups while an agent runs** decides what ⏎ does while a turn is running: off, ⏎ steers the running turn and ⌘⏎ queues; on, ⏎ queues and ⌘⏎ steers.
- **Power**: **Prevent sleep while agents run** keeps your Mac awake (via `caffeinate`, macOS only) so idle sleep cannot interrupt a turn.
- **Workspaces**: **Branch name prefix** is prepended to new workspace branches. Presets are **Recur** (`recur/`), **GitHub** (your `gh` login), or **None**. **Keep scheduled workspaces** keeps the last N workspaces per schedule and removes older finished runs. 0 keeps all.

### Appearance

Pick the **App theme** (chrome, sidebars, panels), the **Code editor theme**, and the **Terminal theme**. Terminal **Match app** follows the app theme. See [Themes](/reference/themes).

### Code editor

- **Editor**: font, font size, line height, wrap, tab size, default indent, per-language indent overrides (Auto follows each language's convention), whitespace and special-character rendering, line numbers, active line, fold gutter, diff gutter (changes versus the workspace base), bracket matching, scroll past end, caret options, rectangular selection, print margin, **Keymap** (Default, Vim, Emacs), and **Max open files** (0 is unlimited).
- **Terminal**: font, size, and line height for the terminal dock (⌃\`). Defaults to the editor font.
- **Code panels**: which side of the editor each Code tool (files, source control, outline, problems, search, and so on) opens on.
- **Files: exclude**: glob patterns hidden from the file explorer. Git-ignored files still appear dimmed unless a pattern matches them. **Reset defaults** restores the shipped list.

### Skills

Turn Recur's built-in skills and your personal skills on or off. Each project can override these and manage its repo skills on its project page. See [Agent skills](/reference/skills).

### Data

- **Logs**: **Reveal in Finder** opens `recur.log`, the process log for crashes and agent failures.
- **Clear all data** deletes all projects, workspaces, and pull requests. Settings are kept. This cannot be undone.

## Agent

### Providers

Turn each provider on or off, see its connection status, and sign in. Turning a provider off keeps its credentials; it only hides its models and stops new turns from using it.

- **Permissions**: **Bypass tool permissions** skips permission prompts in Claude Code and Codex. Off by default.
- **Claude Code**: shows the path, version, login method, and account. Sign in or switch accounts with `claude auth login` in a terminal.
- **Cursor**: **Connect** signs in through your browser. **SDK** installs or updates the Cursor bridge (about 50 MB). **Ignore project Cursor config** skips the repo's `.cursor/rules` and `AGENTS.md` and your `~/.cursor` settings. **Commit attribution** and **PR attribution** let Cursor add its trailer to commits and PRs; both are off by default.
- **Codex**: **Use ChatGPT login** reuses `codex login`; otherwise enter an **API key**. **Sandbox network access** lets Codex Agent commands use the network. **Binary** sets the path to `codex` if Recur cannot find it.
- **OpenAI-compatible**: **Add provider** adds an endpoint. See [Providers](/reference/agents).

### Models

Set the default model and flags (such as effort) for each chat mode: Ask, Plan, Agent / Coder, Review, and Loop. **Workspace titles** sets the model that names new workspaces. **Child workspace model** decides whether a child workspace an agent opens uses the calling chat's model or the default for its mode.

You can always pick a different model per chat in the composer.

## Loops

**Default loop and policy** is used on New Task and for workspaces that have not picked their own. A run keeps the loop and policy it started with. See [Loop mode](/concepts/loop).

## Workflow

### Pull requests

- **Default merge method**: merge commit, squash, or rebase.
- **Default update-with-base method**: merge base into the branch, or rebase onto base, when you click **Update with base**.
- **Squash commit message** and **Merge commit message**: the message presented when merging.

Projects can override each of these. See [Pull requests](/concepts/pull-requests).

### Integrations

Values for bundles that declare `[[setting]]` in `bundle.toml`, such as the Linear API key. A bundle's scripts read these at runtime.

### MCP

Linear and your own MCP servers that chats can use. **Add HTTP** takes a URL and optional Bearer token; **Add stdio** takes a command and arguments. Each project can override these on its project page. See [Integrations & MCP](/reference/integrations).

## Bundles

Turn individual bundle contributions on or off:

- **Commands**: Run Command palette entries, keybindings, and format-on-save.
- **Prompt actions**: chat slash commands such as `/commit` and `/open-pr`.
- **Grammars**: syntax highlighting per file type.
- **Language servers**: install status for each server. Managed servers download on first use; others need the binary on your PATH.
- **Themes**: editor color themes.
- **Snippets**: tab triggers and snippet keybindings.

See [Bundles](/bundles).
