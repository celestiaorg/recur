# Settings

Open Settings with **⌘,** (or **Recur → Settings…**). Type in the search field above the section list to filter sections by keyword. Settings apply to every project; where a project can override one, its project page says so.

## App

### General

- **Simplify**: **Default Simplify** turns Simplify on for new chats. Simplify keeps agents from over-building: they reuse what is already in the repo and ship the smallest change that works. You can still toggle it per chat in the composer.
- **Concurrency**: **Max concurrent workflows** (default 4) and **Max concurrent agents** (default 8). Extra workflows and agent turns wait in a queue until a slot frees. 0 is unlimited.
- **Agents**: **Turn time limit** stops an agent turn after this many minutes (default 240, max 10080). **Queue follow-ups while an agent runs** decides what ⏎ does while a turn is running: off, ⏎ steers the running turn and ⌘⏎ queues; on, ⏎ queues and ⌘⏎ steers.
- **Power**: **Prevent sleep while agents run** keeps your Mac awake (via `caffeinate`, macOS only) so idle sleep cannot interrupt a turn.
- **Workspaces**: **Branch name prefix** is prepended to new workspace branches. Presets are **Recur** (`recur/`), **GitHub** (your `gh` login), or **None**. **Keep scheduled workspaces** keeps the last N workspaces per schedule and removes older finished runs. 0 keeps all.
- **Projects**: **New projects folder** is where Ask Recur creates a project you ask for (`~` works). Blank puts it beside your most recent project.
- **Sidebar**: **Terminals page** (off by default) adds a **Terminals** row under Insights (⌥⌘5) with tabbed shells that belong to no workspace. They start in your home folder and come back after a restart.

### Appearance

Pick the **App theme** (chrome, sidebars, panels), the **Code editor theme**, and the **Terminal theme**. Each can be a single theme or **Sync with system**, with one theme for light mode and one for dark. Terminal **Match app** follows the app theme. See [Themes](/reference/themes).

- **Window**: **Zoom with ⌘ + scroll** (**Ctrl** on Linux) zooms the whole UI, and can be turned off. On Linux, **Use native title bar** shows the system title bar after a restart.

### Code editor

- **Editor**: font, font size, line height, wrap, tab size, default indent, per-language indent overrides (Auto follows each language's convention), whitespace and special-character rendering, line numbers, active line, fold gutter, diff gutter (changes versus the workspace base), bracket matching, scroll past end, caret options, rectangular selection, print margin, **Keymap** (Default, Vim, Emacs), and **Max open files** (0 is unlimited).
- **Terminal**: font, size, and line height for the terminal dock (⌃\`). Defaults to the editor font.
- **Code panels**: whether the right panel is docked beside the editor or floats over it (see [Layout](/concepts/workspaces#layout)), where workspaces show the terminal unless one has its own placement (below the editor, below the chat and editor, in place of the editor, or beside the editor), and which side of the editor each Code tool (files, outline, problems, search, artifacts, and so on) opens on. The plan is a view of the center column, and source control is the review's Uncommitted tab, so they have no side.
- **Files: exclude**: glob patterns hidden from the file explorer. Git-ignored files still appear dimmed unless a pattern matches them. **Reset defaults** restores the shipped list.

### Skills

Turn Recur's built-in skills and your personal skills on or off. Each project can override these and manage its repo skills on its project page. See [Agent skills](/reference/skills).

### Data

- **Logs**: **Reveal in Finder** opens `recur.log`, the process log for crashes and agent failures.
- **Clear all data** deletes all projects, workspaces, and pull requests. Settings are kept. This cannot be undone.

### Licenses

Recur's license and the notices of the open source software it includes.

## Agent

### Providers

Turn each provider on or off, see its connection status, and sign in. Turning a provider off keeps its credentials; it only hides its models and stops new turns from using it. API keys are kept in the macOS Keychain or the Linux Secret Service. See [Where credentials are stored](/reference/agents#where-credentials-are-stored).

- **Permissions**: **Bypass tool permissions** skips permission prompts in Claude Code, Codex, Antigravity and OpenCode, and before shell commands on a ChatGPT account or a compatible endpoint. It also skips Recur's own prompts when an agent starts a [background process](/concepts/background#permission) or creates, edits or deletes a [schedule](/concepts/schedules#agents-can-manage-schedules). Installing a bundle still asks. Off by default.
- **Claude Code**: shows the path, version, login method, and account. Sign in or switch accounts with `claude auth login` in a terminal.
- **Cursor**: **Connect** signs in through your browser. **SDK** installs or updates the Cursor bridge (about 50 MB). **Ignore project Cursor config** skips the repo's `.cursor/rules` and `AGENTS.md` and your `~/.cursor` settings. **Commit attribution** and **PR attribution** let Cursor add its trailer to commits and PRs; both are off by default.
- **OpenAI → ChatGPT account**: **Continue with ChatGPT** signs in through your browser or with a device code. Uses your ChatGPT plan without Codex or an API key. Several accounts can be saved.
- **OpenAI → Codex runtime**: sign in with ChatGPT in Recur, or **Use ChatGPT login** to reuse `codex login`; otherwise enter an **API key**. **Sandbox network access** lets Codex Agent commands use the network. **Binary** sets the path to `codex` if Recur cannot find it.
- **Antigravity** and **OpenCode**: show the path and version, or how to install or sign in. These agents keep their own login, so there is nothing to enter in Recur.
- **OpenAI-compatible**: **Add provider** adds an endpoint. An OpenAI endpoint appears as **API endpoint** under **OpenAI**. See [Providers](/reference/agents).

### Models

Set the default model and flags (such as effort) for each chat mode: Ask, Plan, Agent / Coder, Review, and Autopilot. **Workspace titles** sets the model that names new workspaces. **Child workspace model** decides whether a child workspace an agent opens uses the calling chat's model or the default for its mode.

You can always pick a different model per chat in the composer.

## Workflows

**Default workflow and policy** is used on New Task and for workspaces that have not picked their own. A run keeps the workflow and policy it started with. See [Workflows](/concepts/workflows).

## Connections

### Pull requests

- **Default merge method**: merge commit, squash, or rebase.
- **Default update-with-base method**: merge base into the branch, or rebase onto base, when you click **Update with base**.
- **Squash commit message** and **Merge commit message**: the message presented when merging.
- **Conventional Commits**: agents write `type(scope): summary` commit subjects and PR titles.
- **Automatic fixes**: **Fix merge conflicts automatically**, **Fix failing checks automatically** and **Address review comments automatically**. Each is on until you turn it off. See [Automatic fixes](/concepts/pull-requests#automatic-fixes).

Projects can override the merge, update, message and Conventional Commits settings. See [Pull requests](/concepts/pull-requests).

### Integrations

Values for bundles that declare `[[setting]]` in `bundle.toml`, such as the Linear API key. A bundle's scripts read these at runtime. They are kept with your other [credentials](/reference/agents#where-credentials-are-stored).

### MCP

Linear and your own MCP servers that chats can use. **Add HTTP** takes a URL and optional Bearer token; **Add stdio** takes a command and arguments. Each project can override these on its project page. See [Integrations & MCP](/reference/integrations).

## Bundles

Turn individual bundle contributions on or off:

- **Commands**: Run Command palette entries, keybindings, and format-on-save.
- **Prompt actions**: chat slash commands such as `/commit` and `/open-pr`.
- **Grammars**: syntax highlighting per file type.
- **Language servers**: install status for each server. Managed servers download on first use; others need the binary on your PATH.
- **Themes**: editor color themes.
- **Snippets**: tab triggers and snippet keybindings.

See [Bundles](/bundles).
