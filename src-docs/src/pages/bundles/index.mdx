# Bundles

**Bundles** extend Recur with editor commands, languages, themes, snippets, chat prompts, and workflows. Each bundle is a directory with a `bundle.toml` manifest and any scripts or supporting files it needs.

Shipped packs under the app’s embedded `bundles/` tree are the reference. For your own work, prefer **`~/.recur/bundles`**.

## What you can build

- **Palette commands**: appear in **Run Command** (⌘⇧P), optionally with a keybinding
- **Format-on-save**: `willSave` triggers that transform the buffer before write
- **TypeScript macros**: sandboxed Worker + `@recur/sdk`
- **Shebang tools**: real OS subprocess (`sh`, `python`, `node`, …) with `RECUR_*` env
- **Chat prompts**: reusable slash actions with optional arguments and mode routing
- **Languages and appearance**: grammars, language servers, editor/terminal themes, and snippets
- **Workflows**: your own workflows, with custom roles, a prompt for each phase, and policies. See [Workflows, roles & policies](/bundles/workflows)
- **Settings, search, and task expansion**: saved values and secrets for scripts, `⌘K` search groups, and new-task expanders

## Quick start

The desktop app includes the `recur` CLI. Launch Recur once to install it on your `PATH`.

```bash
recur bundles create MyPack   # → ~/.recur/bundles/MyPack
recur bundles lint MyPack
recur bundles test MyPack
```

After creating or editing a bundle, choose **Navigate → Reload Bundles** to pick up its changes without restarting. Enable or disable individual contributions under **Settings → Bundles**.

## Security

Shebang commands run as **your user** with full OS access. TypeScript macros run in a Worker with a sealed context. Only install bundles you trust. File writes go through Recur’s worktree-gated code service.
