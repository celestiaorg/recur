# Introduction

Recur is a desktop app for macOS and Linux where coding agents don't stop until the work is right. Give a task its own worktree, pair with an agent, or hand it to a workflow: your process, written down, where a team of agents plans, builds, and reviews until the work clears a bar you set. Start one from any chat with a slash command such as `/review-and-fix`, from an issue, or on a schedule.

Each chat picks its own model and one of five modes: **Ask**, **Plan**, **Agent**, **Review**, or **Autopilot**. Your workspace stays on your machine; your chosen model provider receives the prompts and code context it needs. GitHub is optional for local work.

## What sets Recur apart

- **Done means reviewed.** A read-only reviewer files findings, and the work goes round until it clears your bar. See [Workflows](/concepts/workflows).
- **Nothing is final.** Every turn is a checkpoint you can inspect, rewind, or fork. See [Review & checkpoints](/concepts/review).
- **Your process, your rules.** Workflows, roles, and policies live in bundles you can read and rewrite. See [Bundles](/bundles).
- **Works while you sleep.** Prompts and whole workflows run on their own clock. See [Schedules](/concepts/schedules).
- **Your checks are the gate.** A workflow's `run` phase runs a command such as your test suite, and a failure can send the work back with the output. See [Run a command](/concepts/workflows#run-a-command).
- **PRs that stay green.** Recur fixes merge conflicts, failing checks and new review comments on your open PRs in their workspaces. Each can be turned off. See [Automatic fixes](/concepts/pull-requests#automatic-fixes).
- **Events start work.** A Watch schedule runs a command, and each line it prints can start a run. See [Watch](/concepts/schedules#watch).
- **Run everything from Inbox.** Answer questions, approve plans and merge from one view, or ask Ask Recur to start and direct work in any project. See [Inbox](/concepts/inbox).

## Concepts

- [Workflows](/concepts/workflows): specialist agents, review loops, policies, and PRs, started from any chat, an issue, or a schedule.
- [Workspaces](/concepts/workspaces): isolated tasks, your working copy, and landing changes.
- [Chat context](/concepts/chat-context): files, selected code, terminals, and artifacts.
- [Chat modes](/concepts/modes): choose how much to delegate, and hand subtasks to child workspaces.
- [Review & checkpoints](/concepts/review): inspect changes and return to an earlier turn.
- [Pull requests](/concepts/pull-requests): review, comment, fix checks, and merge.
- [Issues](/concepts/issues): GitHub and Linear issues, and starting workspaces from them.
- [Inbox](/concepts/inbox): find work that needs your attention, and direct it with Ask Recur.
- [Schedules](/concepts/schedules): run saved prompts once, on a recurring schedule, or on events.
- [Insights](/concepts/insights): see how your agents spent their time.
- [Background work](/concepts/background): long-running processes, check-backs, and shared todos.
